# 🎵 LyricMind AI

O LyricMind AI é uma aplicação web desenvolvida para auxiliar na criação de letras musicais utilizando Inteligência Artificial e técnicas de Engenharia de Prompt.

O sistema permite que o usuário personalize diferentes aspectos da música, como tema, gênero musical e humor emocional, gerando automaticamente letras organizadas através da integração com APIs de IA.

---

# 🚀 Objetivo do Projeto

O objetivo principal do projeto é demonstrar a utilização de Inteligência Artificial aplicada à criatividade musical, além de praticar conceitos de:

- Desenvolvimento Web
- Engenharia de Prompt
- Integração com APIs
- UX/UI
- JavaScript
- Estruturação Front-End

# ⚙️ Funcionalidades

## ✅ Geração de Letras

O usuário pode:

- Escolher o tema da música
- Escolher o gênero musical
- Escolher o humor da música

A aplicação envia essas informações para a IA através de prompts personalizados.

---

## ✅ Refinamento Musical

O sistema também possui botões de refinamento para modificar ou expandir letras:

- Novo Refrão
- Mais Triste
- Mais Poético

---

## ✅ Integração com Inteligência Artificial

A aplicação realiza integração com a Google Gemini API utilizando JavaScript e requisições HTTP com fetch().
